12. Modelos multinível

  • Mostrar o código
  • Esconder o código
  • Ver o código fonte
Objetivos
  • Reconhecer a dependência entre efeitos de um mesmo estudo.
  • Ajustar um modelo de três níveis com rma.mv().
  • Decompor a heterogeneidade entre e dentro de estudos.

Efeitos não independentes

Os modelos dos capítulos anteriores assumem que cada efeito vem de um estudo independente. Nas ciências agrárias é comum um mesmo artigo relatar vários ensaios (locais, safras, cultivares). Ensaios do mesmo estudo tendem a ser mais parecidos entre si, e tratá-los como independentes subestima a incerteza da média.

O modelo multinível (três níveis) separa as fontes de variação:

\[y_{ij} = \mu + u_j + w_{ij} + \varepsilon_{ij}\]

  • \(\varepsilon_{ij} \sim N(0, v_{ij})\): erro amostral do ensaio \(i\) no estudo \(j\) (nível 1);
  • \(w_{ij} \sim N(0, \sigma^2_{\text{ensaio}})\): variação entre ensaios dentro do estudo (nível 2);
  • \(u_j \sim N(0, \sigma^2_{\text{estudo}})\): variação entre estudos (nível 3).

O nível de estudo é necessário?

Comparamos o modelo completo com outro sem a variância entre estudos por teste de razão de verossimilhança:

m3_sem_estudo <- rma.mv(yi, vi, random = ~ 1 | estudo/ensaio,
                        sigma2 = c(0, NA), data = dat_m)
anova(m3, m3_sem_estudo)

Distribuição da heterogeneidade

Uma forma de reportar é a proporção da variação total em cada nível (análogo multinível do \(I^2\)):

W <- diag(1 / dat_m$vi)
X <- model.matrix(m3)
P <- W - W %*% X %*% solve(t(X) %*% W %*% X) %*% t(X) %*% W
I2 <- 100 * m3$sigma2 / (sum(m3$sigma2) + (m3$k - m3$p) / sum(diag(P)))
round(c(estudo = I2[1], ensaio = I2[2], total = sum(I2)), 1)
estudo ensaio  total 
  26.9   44.9   71.7

## Efeitos não independentes

Os modelos dos capítulos anteriores assumem que cada efeito vem de um
estudo independente. Nas ciências agrárias é comum um mesmo artigo relatar
**vários ensaios** (locais, safras, cultivares). Ensaios do mesmo estudo
tendem a ser mais parecidos entre si, e tratá-los como independentes
subestima a incerteza da média.

O **modelo multinível** (três níveis) separa as fontes de variação:

$$y_{ij} = \mu + u_j + w_{ij} + \varepsilon_{ij}$$

- $\varepsilon_{ij} \sim N(0, v_{ij})$: erro amostral do ensaio $i$ no
  estudo $j$ (nível 1);
- $w_{ij} \sim N(0, \sigma^2_{\text{ensaio}})$: variação entre ensaios
  dentro do estudo (nível 2);
- $u_j \sim N(0, \sigma^2_{\text{estudo}})$: variação entre estudos
  (nível 3).
