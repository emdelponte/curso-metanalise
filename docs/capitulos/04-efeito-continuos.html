4. Medidas de efeito: dados contínuos

  • Mostrar o código
  • Esconder o código
  • Ver o código fonte
Objetivos
  • Calcular diferença média (MD), diferença média padronizada (SMD) e razão de resposta (ROM).
  • Saber quando usar cada uma.
  • Usar a função escalc() do metafor.

O que é uma medida de efeito?

É a magnitude da diferença entre dois grupos (tratamento × controle) ou da associação entre duas variáveis.

Tipo de dado Comparação Medida escalc(measure = )
Contínuo Tratamento × controle Diferença média "MD"
Contínuo Tratamento × controle Diferença média padronizada "SMD"
Contínuo Tratamento × controle Razão de resposta (log) "ROM"
Binário Tratamento × controle Razão de chances (log) "OR"
Binário Tratamento × controle Risco relativo (log) "RR"
Contínuo Associação Correlação "COR"
Contínuo Associação Z de Fisher "ZCOR"

Diferença média (MD)

\(D = \bar{y}_T - \bar{y}_C\). Use quando todos os estudos medem a resposta na mesma escala (ex.: kg/ha).

Diferença média padronizada (SMD)

Quando os estudos usam escalas diferentes (notas × percentual), padroniza-se pela variabilidade combinada (d de Cohen). O argumento "SMD" do escalc() aplica a correção para amostras pequenas e retorna o g de Hedges.

Razão de resposta (ROM)

Quando interessa a diferença relativa. Como a razão não tem boa distribuição, usa-se o log natural:

\[\ln RR = \ln\left(\frac{\bar{y}_T}{\bar{y}_C}\right) = \ln \bar{y}_T - \ln \bar{y}_C\]

A variável precisa ter um zero natural.

Exemplo: tebuconazol e giberela do trigo

A eficácia de controle é obtida da razão de resposta: \(C = (1 - e^{\ln RR}) \times 100\). Se a severidade no tratado é 20% da testemunha, \(\ln RR = \ln 0{,}2\) e \(C = 80\%\).

No R

A função escalc() precisa de média, desvio padrão e n de cada grupo. Quando o artigo traz apenas o CV, usamos \(\sqrt{V} = \frac{CV}{100}\bar{Y}\) como desvio padrão dos dois grupos, o que resulta em \(V_D = 2V/n\) (capítulo 3).

fungicida <- read_csv("dados/fungicida_soja.csv") |>
  mutate(sd = cv / 100 * media_geral)

dat_md <- escalc(measure = "MD",
                 m1i = prod_trat, sd1i = sd, n1i = n,
                 m2i = prod_ctrl, sd2i = sd, n2i = n,
                 data = fungicida)

| Tipo de dado | Comparação | Medida | `escalc(measure = )` |

## Diferença média (MD)

na **mesma escala** (ex.: kg/ha).

## Razão de resposta (ROM)

$$\ln RR = \ln\left(\frac{\bar{y}_T}{\bar{y}_C}\right) = \ln \bar{y}_T - \ln \bar{y}_C$$

A eficácia de controle é obtida da razão de resposta:
$C = (1 - e^{\ln RR}) \times 100$. Se a severidade no tratado é 20% da
