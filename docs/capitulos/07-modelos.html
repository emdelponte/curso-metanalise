Modelo de efeito fixo

Há um efeito verdadeiro comum a todos os estudos. A variação observada é apenas erro amostral:

\[y_i = \theta + \varepsilon_i, \qquad \varepsilon_i \sim N(0, v_i)\]

O efeito sumário é a média ponderada com \(w_i = 1/v_i\).

Modelo de efeitos aleatórios

  1. O efeito verdadeiro varia de um estudo para outro.
  2. Os estudos são uma amostra aleatória da população de estudos possíveis.

\[y_i = \mu + u_i + \varepsilon_i, \qquad u_i \sim N(0, \tau^2)\]

Há duas fontes de variação: dentro do estudo (\(v_i\)) e entre estudos (\(\tau^2\)). Os pesos passam a ser \(w_i = 1/(v_i + \tau^2)\). \(\tau^2\) pode ser estimado por vários métodos (DL, REML etc.).

No R

O fluxo mínimo no metafor:

dat <- escalc(...)          # yi e vi
m   <- rma(yi, vi, data = dat)
forest(m)

## Modelo de efeito fixo

Há **um efeito verdadeiro comum** a todos os estudos. A variação observada
é apenas erro amostral:

$$y_i = \theta + \varepsilon_i, \qquad \varepsilon_i \sim N(0, v_i)$$

## Modelo de efeitos aleatórios

1. O efeito verdadeiro **varia** de um estudo para outro.
2. Os estudos são uma amostra aleatória da população de estudos possíveis.

$$y_i = \mu + u_i + \varepsilon_i, \qquad u_i \sim N(0, \tau^2)$$

Há duas fontes de variação: **dentro** do estudo ($v_i$) e **entre**
estudos ($\tau^2$). Os pesos passam a ser $w_i = 1/(v_i + \tau^2)$.
$\tau^2$ pode ser estimado por vários métodos (DL, REML etc.).
