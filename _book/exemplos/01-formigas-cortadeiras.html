Exemplo 1 · Formigas cortadeiras, solo e plantas

Reproduzindo a análise global de Farji-Brener & Werenkraut (2015) com dados simulados

Objetivos
  • Entender a pergunta, os dados e os métodos de uma metanálise publicada em entomologia (Farji-Brener e Werenkraut 2015).
  • Simular dados com o mesmo desenho e reproduzir a análise global (sem moderadoras).
  • Ver, passo a passo, como lidar com vários efeitos por estudo e como checar viés de publicação.
Dados simulados

Os dados deste exemplo não são os do artigo. Eles foram gerados por R/gerar-dados-formigas.R com o mesmo número de estudos e de efeitos por variável do artigo e com efeitos médios próximos aos da Figura 1. Por isso os resultados devem se parecer com os publicados, mas não coincidir.

O artigo

Pergunta. As formigas cortadeiras (Atta e Acromyrmex) são consideradas “engenheiras do ecossistema”: o ninho e o material descartado (refuse) acumulam nutrientes. Isso sempre melhora o solo e o crescimento das plantas ao redor do ninho? Estudos isolados dão resultados conflitantes.

Desenho. Cada estudo primário compara sítios com ninho (tratamento) e sítios vizinhos sem ninho (controle). O artigo reuniu 34 estudos independentes e analisou seis variáveis-foco:

Grupo Variável-foco Estudos Efeitos
Fertilidade do solo Nutrientes (C, N, P, K) 19 66
Fertilidade do solo Cátions (Al, Ca, Mg, Na) 13 29
Fertilidade do solo pH 6 7
Desempenho da planta Crescimento (biomassa, altura, diâmetro) 13 26
Desempenho da planta Densidade (cobertura, indivíduos/área) 11 12
Desempenho da planta Riqueza de espécies 8 10

Métodos principais (resumo do que vamos reproduzir):

  1. Medida de efeito: d de Hedges (diferença média padronizada), com valores positivos indicando mais fertilidade ou desempenho no ninho.
  2. Vários efeitos por estudo: um mesmo estudo mede C, N, P e K na mesma amostra de solo. Para evitar pseudo-replicação, cada estudo gera um efeito composto por variável-foco: a média ponderada dos efeitos, com variância calculada sob correlação r = 0 e sob r = 1 entre as medidas (análise de sensibilidade) (Mengersen, Jennions, e Schmid 2013).
  3. Modelo: efeitos aleatórios, escolhido a priori, com IC 95% bootstrap corrigido para viés (999 reexecuções) no MetaWin (Rosenberg, Adams, e Gurevitch 2000).
  4. Viés de publicação: gráficos de quantis normais, fail-safe N de Rosenthal e de Rosenberg, funil, teste de correlação de postos de Begg e trim-and-fill, no metafor.
O que fica de fora

O artigo também testa moderadoras (substrato, local do descarte, gênero da formiga e latitude). Aqui reproduzimos só a análise global; as moderadoras seguem a mesma lógica do capítulo 9.

Passo 2: um efeito composto por estudo

Um estudo com quatro nutrientes tem quatro efeitos correlacionados (vêm da mesma amostra de solo). Se os usássemos separados, o estudo teria peso quatro vezes maior. A solução é resumir cada estudo, em cada variável-foco, em um único efeito.

O estimador é a média ponderada pelo inverso da variância, \(w_i = 1/v_i\). A variância dessa média depende da correlação \(r\) entre as medidas, que quase nunca é relatada:

\[V = \frac{\sum_i\sum_j w_i w_j \, r_{ij}\sqrt{v_i v_j}}{\left(\sum_i w_i\right)^2}, \qquad r_{ii} = 1\]

  • Com \(r = 0\) (medidas independentes) a fórmula reduz a \(V = 1/\sum w_i\), a menor variância possível.
  • Com \(r = 1\) (correlação perfeita) as medidas não trazem informação nova e a variância é a maior possível.
composto <- function(d, r) {
  w <- 1 / d$vi
  est <- sum(w * d$yi) / sum(w)
  # sum(w^2 * vi): termos i = j; (sum(w * sqrt(vi)))^2: todos os pares com r = 1
  var <- (sum(w^2 * d$vi) + r * (sum(w * sqrt(d$vi))^2 - sum(w^2 * d$vi))) /
    sum(w)^2
  tibble(yi = est, vi = var, k = nrow(d))
}

compostos <- map_dfr(c(0, 1), function(r) {
  efeitos |>
    group_by(foco, estudo) |>
    group_modify(~ composto(.x, r)) |>
    ungroup() |>
    mutate(r = r)
})

Passo 3: modelo de efeitos aleatórios

O artigo usa o MetaWin, cujo modelo de efeitos aleatórios estima \(\tau^2\) pelo método de DerSimonian-Laird. No metafor isso é method = "DL".

global <- compostos |>
  group_by(foco, r) |>
  group_modify(function(d, chave) {
    m <- rma(yi, vi, data = d, method = "DL")
    tibble(k = m$k, d = coef(m), ic_inf = m$ci.lb, ic_sup = m$ci.ub,
           p = m$pval, tau2 = m$tau2, I2 = m$I2)
  }) |>
  ungroup()

Os intervalos acima são os de Wald (normais). O artigo usa bootstrap, que não assume normalidade da estimativa.

IC 95% bootstrap corrigido para viés

A ideia: sortear estudos com reposição 999 vezes, reestimar o efeito médio em cada amostra e usar os percentis da distribuição obtida. A correção de viés desloca os percentis de acordo com a proporção de estimativas bootstrap abaixo da estimativa original.

ic_boot <- function(yi, vi, B = 999) {
  est <- coef(rma(yi, vi, method = "DL"))
  b <- replicate(B, {
    i <- sample(length(yi), replace = TRUE)
    coef(rma(yi[i], vi[i], method = "DL"))
  })
  z0 <- qnorm(mean(b < est))
  quantile(b, pnorm(2 * z0 + qnorm(c(0.025, 0.975))), names = FALSE)
}

set.seed(2015)
boot <- compostos |>
  filter(r == 1) |>
  group_by(foco) |>
  group_modify(function(d, chave) {
    ci <- ic_boot(d$yi, d$vi)
    tibble(boot_inf = ci[1], boot_sup = ci[2])
  }) |>
  ungroup()

resultado <- global |>
  filter(r == 1) |>
  left_join(boot, by = "foco") |>
  mutate(signif = boot_inf > 0 | boot_sup < 0)

Viés de publicação

O artigo avalia se estudos com efeito pequeno ou negativo podem estar “faltando”. Vamos repetir as cinco verificações para nutrientes.

1. Gráfico de quantis normais

O que aprendemos

  • Uma metanálise publicada pode ser reproduzida em poucas linhas com escalc() e rma(); o trabalho está em organizar os dados (um efeito por linha, com média, DP e n).
  • Quando um estudo traz várias medidas correlacionadas, resuma-as em um efeito composto e faça a análise de sensibilidade para a correlação.
  • Os modelos multinível do capítulo 12 são uma alternativa a esse composto, pois usam todos os efeitos sem pseudo-replicação.
  • Conclusões com poucos estudos e alta heterogeneidade vêm com intervalos largos; checar viés de publicação é parte do relato.
Farji-Brener, Alejandro G., e Victoria Werenkraut. 2015. «A meta-analysis of leaf-cutting ant nest effects on soil fertility and plant performance». Ecological Entomology 40 (2): 150–58. https://doi.org/10.1111/een.12169.
Mengersen, Kerrie, Michael D. Jennions, e Christopher H. Schmid. 2013. «Statistical models and approaches to compare effect sizes from several studies». Handbook of Meta-analysis in Ecology and Evolution, 89–107.
Rosenberg, Michael S., Dean C. Adams, e Jessica Gurevitch. 2000. MetaWin: Statistical Software for Meta-Analysis. Version 2. Sinauer Associates.

## O artigo

**Pergunta.** As formigas cortadeiras (*Atta* e *Acromyrmex*) são
consideradas "engenheiras do ecossistema": o ninho e o material descartado
(*refuse*) acumulam nutrientes. Isso sempre melhora o solo e o crescimento
das plantas ao redor do ninho? Estudos isolados dão resultados conflitantes.

**Desenho.** Cada estudo primário compara **sítios com ninho** (tratamento)
e **sítios vizinhos sem ninho** (controle). O artigo reuniu 34 estudos
independentes e analisou seis variáveis-foco:

| Grupo | Variável-foco | Estudos | Efeitos |
|---|---|---:|---:|
| Fertilidade do solo | Nutrientes (C, N, P, K) | 19 | 66 |
| Fertilidade do solo | Cátions (Al, Ca, Mg, Na) | 13 | 29 |
| Fertilidade do solo | pH | 6 | 7 |
| Desempenho da planta | Crescimento (biomassa, altura, diâmetro) | 13 | 26 |
| Desempenho da planta | Densidade (cobertura, indivíduos/área) | 11 | 12 |
| Desempenho da planta | Riqueza de espécies | 8 | 10 |

**Métodos principais** (resumo do que vamos reproduzir):

1. **Medida de efeito:** *d* de Hedges (diferença média padronizada), com
   valores positivos indicando mais fertilidade ou desempenho no ninho.
2. **Vários efeitos por estudo:** um mesmo estudo mede C, N, P e K na mesma
   amostra de solo. Para evitar pseudo-replicação, cada estudo gera um
   **efeito composto** por variável-foco: a média ponderada dos efeitos,
   com variância calculada sob **correlação r = 0** e sob **r = 1** entre
   as medidas (análise de sensibilidade) [@mengersen2013].
3. **Modelo:** efeitos aleatórios, escolhido *a priori*, com **IC 95%
   bootstrap** corrigido para viés (999 reexecuções) no MetaWin
   [@rosenberg2000].
4. **Viés de publicação:** gráficos de quantis normais, *fail-safe N* de
   Rosenthal e de Rosenberg, funil, teste de correlação de postos de Begg e
   *trim-and-fill*, no `metafor`.

## Os dados

Os números de estudos e de efeitos coincidem com a tabela acima.

## Passo 1: efeito de cada medida (*d* de Hedges)

```{r}
efeitos <- escalc(measure = "SMD",
                  m1i = media_ninho,    sd1i = dp_ninho,    n1i = n_ninho,
                  m2i = media_controle, sd2i = dp_controle, n2i = n_controle,
                  data = formigas)

efeitos |> select(estudo, foco, medida, yi, vi) |> head(8)
```

`measure = "SMD"` retorna o *g* de Hedges (o *d* corrigido para amostras
pequenas, o mesmo do artigo). Como ninho é o grupo 1, valores positivos
significam mais nutrientes (ou mais crescimento) no ninho.

## Passo 2: um efeito composto por estudo

Um estudo com quatro nutrientes tem quatro efeitos **correlacionados** (vêm
da mesma amostra de solo). Se os usássemos separados, o estudo teria peso
quatro vezes maior. A solução é resumir cada estudo, em cada variável-foco,
em **um único efeito**.

O estimador é a média ponderada pelo inverso da variância, $w_i = 1/v_i$. A
variância dessa média depende da correlação $r$ entre as medidas, que quase
nunca é relatada:

$$V = \frac{\sum_i\sum_j w_i w_j \, r_{ij}\sqrt{v_i v_j}}{\left(\sum_i w_i\right)^2}, \qquad r_{ii} = 1$$

- Com $r = 0$ (medidas independentes) a fórmula reduz a $V = 1/\sum w_i$,
  a menor variância possível.
- Com $r = 1$ (correlação perfeita) as medidas não trazem informação
  nova e a variância é a maior possível.

```{r}
composto <- function(d, r) {
  w <- 1 / d$vi
  est <- sum(w * d$yi) / sum(w)
  # sum(w^2 * vi): termos i = j; (sum(w * sqrt(vi)))^2: todos os pares com r = 1
  var <- (sum(w^2 * d$vi) + r * (sum(w * sqrt(d$vi))^2 - sum(w^2 * d$vi))) /
    sum(w)^2
  tibble(yi = est, vi = var, k = nrow(d))
}

compostos <- map_dfr(c(0, 1), function(r) {
  efeitos |>
    group_by(foco, estudo) |>
    group_modify(~ composto(.x, r)) |>
    ungroup() |>
    mutate(r = r)
})

compostos |> filter(foco == "nutrientes", r == 1) |> head()
```

## Passo 3: modelo de efeitos aleatórios

O artigo usa o MetaWin, cujo modelo de efeitos aleatórios estima $\tau^2$
pelo método de **DerSimonian-Laird**. No `metafor` isso é `method = "DL"`.

```{r}
global <- compostos |>
  group_by(foco, r) |>
  group_modify(function(d, chave) {
    m <- rma(yi, vi, data = d, method = "DL")
    tibble(k = m$k, d = coef(m), ic_inf = m$ci.lb, ic_sup = m$ci.ub,
           p = m$pval, tau2 = m$tau2, I2 = m$I2)
  }) |>
  ungroup()

global |> filter(r == 1)
```

Os intervalos acima são os de Wald (normais). O artigo usa **bootstrap**,
que não assume normalidade da estimativa.

### IC 95% bootstrap corrigido para viés

A ideia: sortear estudos com reposição 999 vezes, reestimar o efeito médio
em cada amostra e usar os percentis da distribuição obtida. A correção de
viés desloca os percentis de acordo com a proporção de estimativas
bootstrap abaixo da estimativa original.

```{r}
ic_boot <- function(yi, vi, B = 999) {
  est <- coef(rma(yi, vi, method = "DL"))
  b <- replicate(B, {
    i <- sample(length(yi), replace = TRUE)
    coef(rma(yi[i], vi[i], method = "DL"))
  })
  z0 <- qnorm(mean(b < est))
  quantile(b, pnorm(2 * z0 + qnorm(c(0.025, 0.975))), names = FALSE)
}

set.seed(2015)
boot <- compostos |>
  filter(r == 1) |>
  group_by(foco) |>
  group_modify(function(d, chave) {
    ci <- ic_boot(d$yi, d$vi)
    tibble(boot_inf = ci[1], boot_sup = ci[2])
  }) |>
  ungroup()

resultado <- global |>
  filter(r == 1) |>
  left_join(boot, by = "foco") |>
  mutate(signif = boot_inf > 0 | boot_sup < 0)

resultado |> select(foco, k, d, boot_inf, boot_sup, signif)
```

Como no artigo, o efeito é considerado significativo a 5% quando o IC
bootstrap **não inclui o zero**.

## Passo 4: análise de sensibilidade (r = 0 × r = 1)

```{r}
global |>
  select(foco, r, d, p) |>
  pivot_wider(names_from = r, values_from = c(d, p), names_sep = "_r") |>
  mutate(across(where(is.numeric), \(x) round(x, 3)))
```

Se as conclusões são as mesmas com os dois extremos de correlação, o
resultado é robusto à escolha de $r$. O artigo apresenta ambos os limites
de P e mostra nas figuras apenas $r = 1$.

## Viés de publicação

O artigo avalia se estudos com efeito pequeno ou negativo podem estar
"faltando". Vamos repetir as cinco verificações para **nutrientes**.

```{r}
nut <- compostos |> filter(foco == "nutrientes", r == 1)
m_nut <- rma(yi, vi, data = nut, method = "DL")
```

### 1. Gráfico de quantis normais

Se os tamanhos de efeito são aproximadamente normais, os pontos ficam sobre
a reta. Lacunas ou assimetria sugerem estudos ausentes.

```{r}
qqnorm(nut$yi, main = "Nutrientes")
qqline(nut$yi)
```

### 2. *Fail-safe N*

Quantos estudos com efeito nulo seriam necessários para anular o resultado?
Rosenthal usa o escore *z* de cada estudo; Rosenberg usa os pesos da
metanálise.

```{r}
fsn(yi, vi, data = nut, type = "Rosenthal")
fsn(yi, vi, data = nut, type = "Rosenberg")
```

Uma regra clássica (Rosenthal) considera o resultado robusto se
*fail-safe N* > 5k + 10, com *k* = `r nrow(nut)` estudos, isto é,
`r 5 * nrow(nut) + 10`.

### 3. Gráfico de funil

```{r}
funnel(m_nut, xlab = "d de Hedges")
```

### 4. Teste de correlação de postos de Begg

Mede a correlação entre o efeito padronizado e sua variância. Correlação
alta indica funil assimétrico.

```{r}
ranktest(m_nut)
```

### 5. *Trim-and-fill*

Estima quantos estudos faltam em cada lado do funil e recalcula a média
com os estudos imputados.

```{r}
trimfill(m_nut, side = "left")
trimfill(m_nut, side = "right")
```

Se o efeito continua significativo depois de imputar os estudos, a
conclusão resiste ao possível viés, como argumentam os autores.

## O que aprendemos

- Uma metanálise publicada pode ser reproduzida em poucas linhas com
  `escalc()` e `rma()`; o trabalho está em **organizar os dados** (um efeito
  por linha, com média, DP e *n*).
- Quando um estudo traz **várias medidas correlacionadas**, resuma-as em um
  efeito composto e faça a análise de sensibilidade para a correlação.
- Os modelos multinível do capítulo 12 são uma alternativa a esse
  composto, pois usam todos os efeitos sem pseudo-replicação.
- Conclusões com poucos estudos e alta heterogeneidade vêm com intervalos
  largos; **checar viés de publicação** é parte do relato.
