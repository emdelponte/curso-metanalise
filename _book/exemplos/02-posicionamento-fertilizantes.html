Exemplo 2 · Posicionamento de fertilizantes e produtividade

  • Mostrar o código
  • Esconder o código
  • Ver o código fonte

Reproduzindo a análise de produtividade de Nkebiwe et al. (2016) com dados simulados

Objetivos
  • Entender a pergunta, os dados e os métodos de uma metanálise publicada em ciência do solo e fitotecnia (Nkebiwe et al. 2016).
  • Calcular a razão de resposta (ln R) por conjunto de dados, o efeito global e o efeito relativo por subgrupo (cultura, técnica, profundidade e tipo de fertilizante).
  • Fazer a análise de sensibilidade e checar o viés de publicação.
  • Discutir um problema do artigo: os conjuntos de dados de um mesmo estudo não são independentes.
Dados simulados

Os dados brutos do artigo (1022 conjuntos de dados) estão no apêndice online da revista e não estavam acessíveis quando este exemplo foi preparado. Os dados abaixo foram gerados por R/gerar-dados-fertilizantes.R: o número de estudos (39), de conjuntos de dados (772) e a distribuição por cultura, técnica e tipo de fertilizante seguem o artigo, e os efeitos médios foram ajustados para ficar próximos das Figuras 2 a 5. Os resultados devem se parecer com os publicados, mas não coincidir. Quando você tiver os dados reais, basta trocar o CSV (veja o final da página).

O artigo

Pergunta. A adubação nitrogenada e fosfatada costuma ser feita a lanço (broadcast), sem garantir que o nutriente esteja no lugar e no momento certos para as raízes. O posicionamento localizado do fertilizante (em banda, sulco, ponto, perto da semente ou profundo) aumenta a produtividade e a absorção de nutrientes em relação ao lanço?

Desenho. Cada conjunto de dados é um par de médias de um ensaio de campo: fertilizante posicionado (tratamento) e fertilizante a lanço (controle), com mesma fonte e dose. Para produtividade foram usados 772 conjuntos de 39 estudos, publicados entre 1982 e 2015. O artigo faz três metanálises (produtividade, concentração e conteúdo de nutrientes); aqui reproduzimos só a de produtividade.

Métodos principais:

  1. Medida de efeito: razão de resposta, \(\ln R = \ln(\bar{X}_E / \bar{X}_C)\), com variância \(V_{\ln R} = \dfrac{S_E^2}{N_E \bar{X}_E^2} + \dfrac{S_C^2}{N_C \bar{X}_C^2}\). Os resultados são expressos como efeito relativo do posicionamento (RPE): \((R - 1) \times 100\%\).
  2. DP faltantes foram imputados: multiplicou-se a média do conjunto pelo CV médio dos conjuntos que reportaram o DP (Furukawa et al. 2006).
  3. Modelo: efeitos aleatórios no MetaWin, com variância pooled (método de DerSimonian-Laird) e IC 95% bootstrap corrigido para viés (999 reexecuções) (Rosenberg, Adams, e Gurevitch 2000).
  4. Subgrupos: cultura, técnica de posicionamento, profundidade e tipo de fertilizante. Grupos com menos de dois conjuntos de dados foram excluídos.
  5. Sensibilidade: sem outliers (±3 DP) e sem os DP imputados.
  6. Viés de publicação: gráfico de funil, gráfico de quantis normais e fail-safe number de Rosenthal.

IC 95% bootstrap corrigido para viés

Como no exemplo anterior, sorteamos os conjuntos de dados com reposição 999 vezes. Para ficar rápido, usamos a estimativa de DerSimonian-Laird escrita à mão.

dl <- function(yi, vi) {
  w <- 1 / vi
  mu_fe <- sum(w * yi) / sum(w)
  Q <- sum(w * (yi - mu_fe)^2)
  C <- sum(w) - sum(w^2) / sum(w)
  tau2 <- max(0, (Q - (length(yi) - 1)) / C)
  wr <- 1 / (vi + tau2)
  sum(wr * yi) / sum(wr)
}

ic_boot <- function(yi, vi, B = 999) {
  est <- dl(yi, vi)
  b <- replicate(B, {
    i <- sample(length(yi), replace = TRUE)
    dl(yi[i], vi[i])
  })
  z0 <- qnorm(mean(b < est))
  quantile(b, pnorm(2 * z0 + qnorm(c(0.025, 0.975))), names = FALSE)
}

set.seed(2016)

Passo 4: subgrupos

O artigo repete a análise em cada nível de quatro variáveis. Vamos escrever uma função que devolve o efeito relativo e o IC bootstrap para cada grupo, excluindo os grupos com menos de dois conjuntos de dados.

por_grupo <- function(dat, var, B = 999) {
  dat |>
    group_by(grupo = .data[[var]]) |>
    filter(n() >= 2) |>
    group_modify(function(d, chave) {
      ci <- ic_boot(d$yi, d$vi, B)
      tibble(n = nrow(d), RPE = rpe(dl(d$yi, d$vi)),
             inf = rpe(ci[1]), sup = rpe(ci[2]))
    }) |>
    ungroup() |>
    mutate(variavel = var, signif = inf > 0 | sup < 0)
}

grafico_grupo <- function(res, titulo) {
  res |>
    mutate(rotulo = paste0(grupo, " (", n, ")"),
           rotulo = fct_reorder(rotulo, RPE)) |>
    ggplot(aes(RPE, rotulo)) +
    geom_vline(xintercept = 0, linetype = "dashed") +
    geom_pointrange(aes(xmin = inf, xmax = sup)) +
    labs(x = "Efeito relativo do posicionamento (%)", y = NULL, title = titulo)
}

Passo 5: análise de sensibilidade

O artigo verifica se o resultado muda ao (1) excluir outliers (efeitos a mais de 3 DP da média) e (2) excluir os conjuntos com DP imputado.

limite <- mean(dat$yi) + c(-3, 3) * sd(dat$yi)
sem_outlier <- dat |> filter(yi > limite[1], yi < limite[2])
so_reportado <- dat |> filter(!dp_imputado)

sens <- tribble(
  ~cenario, ~dados,
  "Todos os dados",       dat,
  "Sem outliers (±3 DP)", sem_outlier,
  "Só DP reportado",      so_reportado,
  "Só DP imputado",       dat |> filter(dp_imputado)
) |>
  mutate(res = map(dados, \(d) {
    m <- rma(yi, vi, data = d, method = "DL")
    tibble(k = m$k, RPE = rpe(coef(m)), inf = rpe(m$ci.lb), sup = rpe(m$ci.ub))
  })) |>
  select(-dados) |>
  unnest(res)

Atenção: os conjuntos de dados não são independentes

O artigo trata os 772 conjuntos de dados como independentes, embora venham de apenas 39 estudos (alguns estudos contribuem com dezenas de conjuntos). Conjuntos do mesmo estudo compartilham local, cultivar, manejo e autores. Isso torna o IC estreito demais. É o tema do capítulo 12: um modelo multinível com estudo e conjunto de dados como níveis aleatórios.

m_mv <- rma.mv(yi, vi, random = ~ 1 | estudo / conjunto, data = dat)

## O artigo

**Pergunta.** A adubação nitrogenada e fosfatada costuma ser feita **a
lanço** (*broadcast*), sem garantir que o nutriente esteja no lugar e no
momento certos para as raízes. O **posicionamento localizado** do fertilizante
(em banda, sulco, ponto, perto da semente ou profundo) aumenta a
produtividade e a absorção de nutrientes em relação ao lanço?

**Desenho.** Cada conjunto de dados é um par de médias de um ensaio de campo:
fertilizante **posicionado** (tratamento) e fertilizante **a lanço**
(controle), com mesma fonte e dose. Para produtividade foram usados 772
conjuntos de 39 estudos, publicados entre 1982 e 2015. O artigo faz três
metanálises (produtividade, concentração e conteúdo de nutrientes); aqui
reproduzimos **só a de produtividade**.

**Métodos principais**:

1. **Medida de efeito:** razão de resposta, $\ln R = \ln(\bar{X}_E / \bar{X}_C)$,
   com variância
   $V_{\ln R} = \dfrac{S_E^2}{N_E \bar{X}_E^2} + \dfrac{S_C^2}{N_C \bar{X}_C^2}$.
   Os resultados são expressos como **efeito relativo do posicionamento**
   (RPE): $(R - 1) \times 100\%$.
2. **DP faltantes** foram **imputados**: multiplicou-se a média do conjunto
   pelo CV médio dos conjuntos que reportaram o DP [@furukawa2006].
3. **Modelo:** efeitos aleatórios no MetaWin, com variância *pooled* (método
   de DerSimonian-Laird) e **IC 95% bootstrap** corrigido para viés
   (999 reexecuções) [@rosenberg2000].
4. **Subgrupos:** cultura, técnica de posicionamento, profundidade e tipo de
   fertilizante. Grupos com menos de dois conjuntos de dados foram excluídos.
5. **Sensibilidade:** sem *outliers* (±3 DP) e sem os DP imputados.
6. **Viés de publicação:** gráfico de funil, gráfico de quantis normais e
   *fail-safe number* de Rosenthal.

### IC 95% bootstrap corrigido para viés

Como no exemplo anterior, sorteamos os conjuntos de dados com reposição 999
vezes. Para ficar rápido, usamos a estimativa de DerSimonian-Laird escrita à
mão.

```{r}
dl <- function(yi, vi) {
  w <- 1 / vi
  mu_fe <- sum(w * yi) / sum(w)
  Q <- sum(w * (yi - mu_fe)^2)
  C <- sum(w) - sum(w^2) / sum(w)
  tau2 <- max(0, (Q - (length(yi) - 1)) / C)
  wr <- 1 / (vi + tau2)
  sum(wr * yi) / sum(wr)
}

ic_boot <- function(yi, vi, B = 999) {
  est <- dl(yi, vi)
  b <- replicate(B, {
    i <- sample(length(yi), replace = TRUE)
    dl(yi[i], vi[i])
  })
  z0 <- qnorm(mean(b < est))
  quantile(b, pnorm(2 * z0 + qnorm(c(0.025, 0.975))), names = FALSE)
}

set.seed(2016)
ci <- ic_boot(dat$yi, dat$vi)
c(RPE = rpe(dl(dat$yi, dat$vi)), inf = rpe(ci[1]), sup = rpe(ci[2]))
```

O efeito é positivo e o IC bootstrap não inclui zero: o posicionamento
aumenta a produtividade em relação ao lanço. O artigo obteve **3,7%** (IC95%
3,1 a 4,3).

## Passo 4: subgrupos

O artigo repete a análise em cada nível de quatro variáveis. Vamos escrever
uma função que devolve o efeito relativo e o IC bootstrap para cada grupo,
excluindo os grupos com menos de dois conjuntos de dados.

```{r}
por_grupo <- function(dat, var, B = 999) {
  dat |>
    group_by(grupo = .data[[var]]) |>
    filter(n() >= 2) |>
    group_modify(function(d, chave) {
      ci <- ic_boot(d$yi, d$vi, B)
      tibble(n = nrow(d), RPE = rpe(dl(d$yi, d$vi)),
             inf = rpe(ci[1]), sup = rpe(ci[2]))
    }) |>
    ungroup() |>
    mutate(variavel = var, signif = inf > 0 | sup < 0)
}

grafico_grupo <- function(res, titulo) {
  res |>
    mutate(rotulo = paste0(grupo, " (", n, ")"),
           rotulo = fct_reorder(rotulo, RPE)) |>
    ggplot(aes(RPE, rotulo)) +
    geom_vline(xintercept = 0, linetype = "dashed") +
    geom_pointrange(aes(xmin = inf, xmax = sup)) +
    labs(x = "Efeito relativo do posicionamento (%)", y = NULL, title = titulo)
}
```

## Atenção: os conjuntos de dados não são independentes

O artigo trata os 772 conjuntos de dados como independentes, embora venham de

## O que aprendemos

- A **razão de resposta** é a medida natural quando o efeito é proporcional à
  produtividade, e vira o **efeito relativo (%)** com $(e^{\ln R} - 1) \times 100$.
- A **imputação de DP** permite aproveitar mais estudos, mas deve ser
  registrada e testada na sensibilidade.
- O **IC bootstrap** e a comparação entre subgrupos pela **sobreposição dos
  IC** são práticas comuns, mas o teste $Q_M$ dá um critério formal.
- Muitos conjuntos de dados por estudo exigem um modelo que reconheça a
  **dependência** entre eles.
