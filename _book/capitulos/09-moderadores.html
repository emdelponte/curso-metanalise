Objetivos
  • Explicar heterogeneidade com moderadoras categóricas (subgrupos) e contínuas (meta-regressão).
  • Visualizar o efeito de moderadoras.

Quando há heterogeneidade

Podemos tentar explicá-la com características dos estudos (moderadoras), em um modelo de efeitos mistos:

  • Análise de subgrupos: moderadora categórica (região, cultivar, pressão de doença).
  • Meta-regressão: moderadora contínua (latitude, ano, severidade na testemunha).

Exemplos em fitopatologia: Ngugi, Esker, e Scherm (2011), Paul, Lipps, e Madden (2005), Paul et al. (2011).

## Quando há heterogeneidade

Podemos tentar explicá-la com características dos estudos (moderadoras),
em um **modelo de efeitos mistos**:

- **Análise de subgrupos**: moderadora categórica (região, cultivar,
  pressão de doença).
- **Meta-regressão**: moderadora contínua (latitude, ano, severidade na
  testemunha).

Exemplos em fitopatologia: @ngugi2011, @paul2005, @paul2011.

## Subgrupos

Nos ensaios de fungicida, a resposta difere entre regiões ou entre níveis
de pressão de doença?

```{r}
m_sub <- rma(yi, vi, mods = ~ pressao, data = dat)
m_sub
```

O teste `QM` (*Test of Moderators*) indica se a moderadora explica parte da
heterogeneidade. Para obter a média de cada grupo, retire o intercepto:

```{r}
rma(yi, vi, mods = ~ pressao - 1, data = dat)
```

## Meta-regressão

```{r}
m_reg <- rma(yi, vi, mods = ~ latitude, data = dat)
m_reg
```

```{r}
regplot(m_reg, xlab = "Latitude (°S)",
        ylab = "Diferença de produtividade (kg/ha)")
```

A mesma figura com `ggplot2` (tamanho do ponto ∝ peso):

```{r}
dat |>
  as_tibble() |>
  ggplot(aes(latitude, yi, size = 1 / vi)) +
  geom_point(shape = 1) +
  geom_abline(intercept = coef(m_reg)[1], slope = coef(m_reg)[2]) +
  labs(x = "Latitude (°S)", y = "Diferença de produtividade (kg/ha)",
       size = "Peso")
```
